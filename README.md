Academic Projects | Master's degree in Applied Mathematics 
This repository contains key projects developed during my Master's degree at University Paris Dauphine - PSL and during my exchange at University of Helsinki.

1. Real Estate Price Prediction
A comprehensive data science project focused on predicting housing prices using supervised learning techniques.
Objective: Build a robust regression model to estimate property values based on various features.
Methodology:EDA: Conducted Exploratory Data Analysis to identify correlations and handle outliers.
Modeling: Implemented and compared multiple algorithms including Linear & Polynomial Regression, Ridge, Lasso, ElasticNet, and KNN.
Evaluation: Used RMSE and $R^2$ metrics for model selection and hyperparameter tuning.
Tools: Python (Scikit-Learn, Pandas, NumPy, Matplotlib)

2. Saturation Vapour Pressure Prediction
This project utilizes machine learning to predict the saturation vapour pressure  of atmospheric molecules using the GeckoQ dataset (31,637 molecules).
Methodology:Performed Feature Engineering on molecular structures (functional groups, molecular weight).
Handled skewed distributions and performed correlation analysis.
Modeling: Implemented Regularized Regressions (Ridge, Lasso) and Random Forest to capture non-linear physical relationships.
Tools: Python (Scikit-Learn, NumPy, Pandas, Matplotlib).
